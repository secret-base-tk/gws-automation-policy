プライバシーポリシー

最終更新: 2026年9月13日

1. 適用範囲

本ポリシーは、個人用ツール「GWS Automation」（以下「本ツール」）に適用されます。 本ツールは、開発者本人が自身の個人アカウント、および本人が運営する法人のアカウントを 管理するために使用するコマンドラインツールであり、一般に配布・販売・提供していません。 利用者は開発者本人のみです。

本ポリシーは、以下の Google Cloud プロジェクトに登録されたアプリケーションに共通して適用されます。

  • Personal - GWS Automation（個人アカウント用）
  • LifeShift - GWS Automation（LifeShift合同会社のアカウント用）

2. 取得する情報

本ツールは、利用者本人が Google の認証画面で明示的に許可した範囲でのみ、以下のデータにアクセスします。

対象用途
Gmail のメール・ラベルメールの棚卸し、ラベル整理、不要メールの削除
Google ドライブのファイル情報ファイルの棚卸しと整理
スプレッドシート / ドキュメント整理作業用の一覧表・記録の作成と更新
カレンダーの予定予定の棚卸しと整理
連絡先重複・旧アドレスの整理
ToDo リストタスクの整理

実際にアクセスする範囲は、認証時に Google が提示する権限（スコープ）に限られます。 許可していない範囲のデータにはアクセスしません。

3. 利用目的

取得したデータは、利用者本人のアカウント整理・管理という目的のためだけに使用します。 それ以外の目的では使用しません。

4. データの保存と管理

  • 取得したデータは、利用者本人のローカル環境（個人所有の PC）にのみ保存されます。
  • 本ツールは外部サーバーを持たず、取得したデータを外部に送信しません。
  • アクセストークン等の認証情報は、OS のキーチェーンおよび利用者本人のパスワードマネージャーに保管されます。

5. 第三者への提供

取得したデータを第三者に提供、販売、貸与、共有することは一切ありません。 広告目的での利用、および機械学習モデルの学習データとしての利用も行いません。

6. Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の利用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。

7. データの削除

利用者は Google アカウントの「サードパーティ製アプリとサービス」 から、本ツールのアクセス権をいつでも取り消すことができます。 ローカルに保存されたデータおよび認証情報は、利用者自身が削除できます。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページの「最終更新」日を改めます。
